## 背景
vintage（即古着，衣服的一种）商品因其复古风格受到追捧。目前，vintage 主要销售渠道为：淘宝、闲鱼、微商等，其中微商因其经营者多、种类丰富、价格实惠等优点，成为主要销售渠道，主要利用“微商相册”小程序进行售卖。

在实际使用场景中，发现在挑选商品的过程中会遇到尺码匹配的问题：与现代衣物商品不同的是，vintage因其年代久、产地广、品牌多等特性导致无法按照常规尺码（如 L、XL 等）进行选购，更多依赖自身身体数据与衣物实际测量数据进行匹配。因此，常规的按尺码筛选不能满足实际需求。

为解决这一问题，尝试设计一个古着多轮导购agent，从引导用户测量身体数据，到理解客户意图（即想要的商品或风格），再到匹配相应的商品，最后到根据顾客的意见给出搭配建议。

CAUTION：该项目仅为个人想法实现，不参与任何支付，不对接任何平台。所有衣服及身体数据均为编造。

## 实施
### 阶段一 数据层
该项目使用 MySQL 数据库，记录商品数据，商品图片则存放在本地文件夹，数据库只记录 URL，避免造成数据库臃肿，提高检索效率。

#### 环境与连接
- MySQL 8.0，库名 vintage_shop，字符集 utf8mb4 / utf8mb4_unicode_ci，支持花体字及emoji 表情
- 专用账号 vintage@localhost，避免误操作影响其余数据库，不使用 root
- 密码通过 .env 注入，保证安全性

#### 表结构设计
- products：sku 做主键（货号唯一）；加 description TEXT 存详情页卖点，便于 agent 匹配用户需求
- measurements：一个 sku 一条；length_cm 存后衣长，前衣长差异写进 description
- images：图片存 static/images/，库中只存 URL
- 外键 ON DELETE CASCADE：删商品级联删尺寸和图片
- price 可空
